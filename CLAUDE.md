# Working rules for this project

- Only change what is explicitly requested in the current message. Do not "fix", tidy up, or
  adjust other code you notice along the way (styles, markup, config, etc.), even if it looks
  inconsistent or broken to you.
- If you notice something that seems off but wasn't asked about, point it out in your reply
  and let the user decide — don't change it yourself.
- Manual edits made directly by the user (including ones that look unusual, e.g. a removed CSS
  property) are intentional. Never "restore" or revert them on your own.
